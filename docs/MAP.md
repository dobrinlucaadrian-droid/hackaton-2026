## Start here (every session)

**Stage:** waiting for the hackathon theme → `/ideate` when it arrives

1. Rules are in `CLAUDE.md`. Reply to the team in simple Romanian; ask before building.
2. Read "Acum lucrăm la" and the newest "Jurnal" entry in `docs/LEDGER.md` instead of rediscovering the state.
3. Find code through the "Code" section below — no exploratory searching.
4. After any code change: add a `docs/LEDGER.md` entry, then `node scripts/gate.mjs`.

## Skills (`.claude/skills`)

- `/coordonator` — Organizes the hackathon team
- `/debugging` — Use when something is broken
- `/deploy-demo` — Deploy the project and run the pre-demo checklist
- `/foreman` — Act as foreman for a large task
- `/gate` — Use after every finished feature or work package, before saying something is done or works, before deploy and before the demo, …
- `/git-workflow` — Fast, consistent git flow for the hackathon
- `/ideate` — Start of the hackathon workflow
- `/pitch` — Produce the hackathon submission material
- `/researcher` — Search GitHub for repositories and code the project can reuse or learn from, and return a ranked report with relevant code exam…
- `/scaffold-feature` — Add a new feature end to end (UI, API, data, types) following the project's existing conventions
- `/token-budget` — Balanced token usage

## Agents (`.claude/agents`)

- `backend` (sonnet) — Implements server-side work
- `frontend` (sonnet) — Implements UI work
- `ideator` (sonnet) — Finds the winning hackathon idea
- `researcher` (sonnet) — Searches GitHub for repositories and code examples that answer a technical question for the project, and returns a ranked report
- `reviewer` (sonnet) — Read-only review of a diff for bugs that would break the demo, contract mismatches between frontend and backend, and leaked sec…
- `tester` (haiku) — Runs the quality gate, the app and its tests, walks the flows it is given and reports what passes and what fails

## Scripts

- `node scripts/gate.mjs` — Quality gate. Runs the mechanical checks and prints TRECUT / PICAT / NEVERIFICAT.
- `node scripts/map.mjs` — Generates docs/MAP.md (stage, skills, agents, code files) and refreshes the commit list in docs/LEDGER.md.
