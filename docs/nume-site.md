# Numele site-ului — unde am rămas

Stare la 2026-10-12: **nu s-a hotărât încă niciun nume.** Numele trebuie ales înainte de a cumpăra domeniul
(vezi `docs/ultimii-pasi.md`, pasul 2).

De ce e nevoie de un nume nou: `unipath.ro` și `unipath.com` sunt deja înregistrate de altcineva
(verificat la registrele oficiale pe 2026-10-12).

## Filtrul ales de echipă (2026-10-12)

- amestec de română și engleză;
- fără cifre și fără argou;
- să sune modern, ca o aplicație;
- să se vadă în nume și liceul, și drumul.

## Favorite pe acest filtru (NEVERIFICATE: nici domeniul, nici marca)

| Nume | Din ce e făcut | Observații |
| --- | --- | --- |
| BacUp | bac + up | sună și ca „backup”; drumul e doar sugerat |
| BacBound | bac + bound (cu destinația) | „bound” înseamnă și „legat” |
| BacWay | bac + way | scurt, clar |
| BacBridge | bac + bridge | puntea dintre bac și facultate |
| BacPack | bac + pack | sună ca „backpack”; probabil folosit deja |
| LicWay | liceu + way | „Lic” poate să nu fie recunoscut din prima |
| LicRoute | liceu + route | ca o aplicație de navigație |
| LicLine | liceu + line | ca o linie de metrou liceu → facultate |
| ElevPath | elev + path | cel mai aproape de UniPath |
| ElevUp | elev + up | amintește de „level up” |
| Elevel | elev + level | un singur cuvânt |
| AbsolvPath | absolv(ent) + path | serios, 10 litere |

De ținut minte:

- în engleză „lice” înseamnă „păduchi”: numele care încep cu „Lice” (LiceNav, LiceLink, Liceway, Licevia) pot fi citite greșit;
- „drum” înseamnă „tobă” în engleză (TeenDrum, CampusDrum);
- „Bac” leagă numele de România și de Franța.
