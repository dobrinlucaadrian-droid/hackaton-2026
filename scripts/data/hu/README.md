## Why none could be used

No official, openly licensed bulk file of Hungarian bachelor programmes per institution was found. The only complete source (felvi.hu) is a search portal without published reuse terms.

## If it is needed later

Ask the Oktatási Hivatal whether the FIR "meghirdetett képzések" (announced programmes) can be provided as open data, and retry data.gov.hu when it is reachable (search "felsőoktatási", "felvi", "alapképzés").
